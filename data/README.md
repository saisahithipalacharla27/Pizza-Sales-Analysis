# Dataset

The pizza sales dataset is used for transactional sales analysis.

The dataset contains information related to:

- Orders
- Pizza quantity
- Order date and time
- Unit price
- Total price
- Pizza size
- Pizza category
- Pizza ingredients
- Pizza name

## Data Availability

The SQL scripts demonstrate the database creation, data ingestion,
transformation, and analytical workflow used in the project.

Please refer to the SQL folder for the analysis workflow.
